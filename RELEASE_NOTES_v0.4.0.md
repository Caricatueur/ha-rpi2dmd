# HA RPI2DMD v0.4.0

## Added

- Zeroconf discovery
- Six-digit physical pairing
- Reauthentication flow
- Stable RPI2DMD hardware identity

## Improved

- Host selection `.local > IPv4 > IPv6`
- Automatic host update
- Entity identity migration
- Brightness schedule migration

## Fixed

- Duplicate ConfigEntries
- `entity_id` `_2` recovery
- `EntityCategory` diagnostic compatibility
- Network address changes after reflashing

## Compatibility

Validated with Home Assistant Core 2026.9.2 and Home Assistant OS 18.2.
